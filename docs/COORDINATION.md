## قواعد
1. هر AI روی شاخه‌ی جدا می‌نویسد: `ai-a/*` و `ai-b/*`.
2. merge فقط توسط مالک (owner) انجام می‌شود.
3. کارِ «ادعاشده» توسط دیگری را تکرار نکن؛ اگر مرز تداخل دارد، در همین فایل ثبت کن.
4. هر تغییر: selftest سبز + commit message فارسی.

### `ai-a/hardening` (AI-A) — ۲۰۲۶-۰۹-۱۵
تغییرات (۴ فایل: `bot/persian.py`, `bot/store.py`, `bot/talk.py`, `bot/bot.py`)، selftest **۵۲/۵۲**:
